## 🧠 Core Principles

### 1. **Single Source of Truth: `weather_service.py`**
All business logic must live here:
- Calling all data sources
- Merging results
- Error handling (graceful failures)
- Caching decisions
- Logging (what worked, what failed, response times)

### 2. **Data Sources: `sources.py`**
Define as functions, not classes:
```python
def get_weather_open_meteo(lat, lon) -> dict:
    """Returns {source: 'open_meteo', data: {...}}"""
    
def get_weather_openweathermap(lat, lon) -> dict:
    """Returns {source: 'owm', data: {...}}"""
```

All must return **same schema** for easy merging.

### 3. **CLI Must Be Powerful**
Commands like:
- `python cli.py current --lat 6.24 --lon -75.58` → show current weather from all sources
- `python cli.py sources` → list available sources
- `python cli.py save` → save merged data
- `python cli.py history` → show historical data

Output: **clean tables, not raw JSON**.

### 4. **API Is Minimal**
Only define endpoints. Call `weather_service` for all logic.

### 5. **Dashboard Reuses Backend**
Calls `weather_service` directly. Includes:
- Map with lat/lon marker
- Data from multiple sources
- Proper caching to prevent freezes
